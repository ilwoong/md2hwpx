# 문단 스타일 지정

이 문단은 기본 `본문` 스타일입니다.

::: {custom-style="요약문-본문"}
이 문단은 템플릿의 `요약문-본문` 스타일입니다.

> 인용문 안의 문단도 같은 스타일입니다.

- 목록 항목은 `본문` 스타일 그대로입니다.
:::

:::: {custom-style="요약문-본문"}
바깥 div 의 문단입니다 (`요약문-본문`).

::: {custom-style="표준"}
안쪽 div 의 문단입니다 (`표준`).
:::
::::

::: {custom-style="없는 스타일"}
템플릿에 없는 스타일이라 `본문` 으로 들어가고 경고가 나옵니다.
:::
