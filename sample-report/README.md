# 보고서 작성 안내

이 폴더는 markdown 으로 보고서를 쓰고 md2hwpx 로 한/글 문서(hwpx)를 만드는 예제입니다.
폴더를 통째로 복사한 뒤 내용을 바꿔 쓰면 됩니다.

이 파일은 front matter 에 `draft: true` 가 있어 변환되는 문서에는 들어가지 않습니다.

## 폴더 구성

| 파일 | 내용 |
| --- | --- |
| `0_1-front.md` | 표지 |
| `0_2-abstract.md` | 요약문 |
| `0_3-toc.md` | 제목 차례, 표 차례, 그림 차례 |
| `ch_1.md` | 1장. 본문의 쪽 번호를 여기서 새로 시작 |
| `ch_2.md` | 2장. 본문 문법(문단, 목록, 수식, 코드블록, 그림, 표)의 예시 |
| `ch_3.md` | 3장. 주석 마커의 예시 |
| `y.md` | 참고문헌 |
| `z.md` | 약어표 |
| `images/` | 본문에 넣는 그림 |

- 폴더 바로 안의 `.md` 파일을 **이름 순**으로 이어 붙여 문서 하나로 만듭니다. 그래서 파일 이름이 곧 문서의 순서입니다.
  숫자는 크기 순으로 읽으므로 `ch_2.md` 다음에 `ch_10.md` 가 옵니다.
- 하위 폴더의 `.md` 파일은 읽지 않습니다.
- 장을 더하려면 `ch_4.md` 처럼 파일을 더하고 `#` 제목으로 시작합니다.

## front matter

파일 맨 앞의 `---` 사이에 적은 내용은 문서에 들어가지 않습니다. `title`, `author` 는 원고를 관리하기 위한 것이고, 변환에는 다음 두 가지만 쓰입니다.

| 키 | 하는 일 |
| --- | --- |
| `draft: true` | 그 파일을 변환에서 뺍니다. 아직 쓰는 중인 장에 씁니다. |
| `caption-numbering: document` | 표·그림 번호를 장 번호 없이 문서 전체에서 셉니다 (`[표 7]`). 쓰지 않으면 장마다 셉니다 (`[표 2-1]`). |

## 변환

```sh
# 폴더 전체를 문서 하나로
/path/to/md2hwpx/md2hwpx.sh sample-report/ -o 결과/

# 2장만 변환하면서 표·그림 번호를 2장에 맞추기
/path/to/md2hwpx/md2hwpx.sh sample-report/ --include 'ch_2*.md' --chapter-start 2 -o 결과/

# 템플릿 지정
/path/to/md2hwpx/md2hwpx.sh sample-report/ -t 내템플릿.hwpx -o 결과/

# draft 파일도 포함
/path/to/md2hwpx/md2hwpx.sh sample-report/ --include-draft -o 결과/
```

- 결과는 `결과/sample-report.hwpx` 로 저장됩니다. 같은 이름의 파일이 있으면 덮어쓰지 않고 `sample-report-1.hwpx` 로 저장됩니다.
- `-t` 를 쓰지 않으면 현재 폴더의 `template.hwpx`, 그것도 없으면 내장 템플릿을 씁니다.

## 템플릿

글꼴, 여백, 제목의 모양은 모두 템플릿의 스타일이 정합니다. 원고에서는 모양을 정하지 않습니다.

- 내장 템플릿의 문단 스타일: `본문`, `개요 1` ~ `개요 6`, `표그림 제목`, `표 헤더`, `요약문-본문`, `글머리표 1` ~ `글머리표 3`, `차례 제목`, `차례 1` ~ `차례 3` 등
- `y.md` 는 `참고문헌` 스타일을 씁니다. 내장 템플릿에는 없으므로, 그 스타일이 있는 템플릿을 `-t` 로 지정합니다.
  없는 채로 변환하면 `본문` 스타일로 들어가고 경고가 나옵니다.
- 표지의 모양(가운데 정렬, 큰 글자)도 템플릿에 표지용 스타일을 만들고 `스타일` 주석 마커로 적용합니다.

## 경고 읽기

변환은 문제가 있어도 가능한 만큼 문서를 만들고, 문제마다 `파일:줄` 과 함께 경고를 냅니다.

```
md2hwpx: 경고: sample-report/ch_2.md:183: 이미지 파일이 없어 대체 이미지를 넣었습니다: sample-report/images/not_existing.png
md2hwpx: 경고: sample-report/y.md:10: 템플릿에 '참고문헌' 문단 스타일이 없어 본문 스타일로 넣었습니다
```

위 두 경고는 이 예제가 일부러 남겨 둔 것입니다. 첫째는 없는 그림을 넣었을 때의 예시이고, 둘째는 내장 템플릿으로 변환했기 때문입니다.

## 자주 하는 실수

- **수식의 공백**: `$ x $` 처럼 `$` 안쪽에 공백이 있으면 수식이 되지 않습니다. `$x$` 로 씁니다.
- **주석 마커를 글과 같은 줄에**: 주석 마커는 한 줄에 하나만, 다른 글 없이 씁니다.
- **명령어 띄어쓰기**: `쪽 나눔`, `새 번호` 가 아니라 `쪽나눔`, `새번호` 입니다.
- **`열너비`·`그림크기` 와 대상 사이에 다른 내용**: 두 명령어는 바로 다음 표·그림에 적용됩니다.
- **제목 줄의 이름**: `[표 #이름] 제목` 에서 `#이름` 앞에는 공백이 있어야 하고, 이름에는 공백을 쓸 수 없습니다.
- **같은 이름을 두 번**: 표·그림의 이름은 문서 전체에서 하나여야 합니다. 파일이 달라도 같은 이름을 쓰면 참조가 되지 않습니다.
- **각주 이름**: 각주는 파일마다 따로이므로, 다른 파일의 각주를 참조할 수 없습니다.
- **목록의 깊이**: 목록은 3단계까지입니다.
- **표기를 글자 그대로**: `[표] 제목`, `[@이름]` 을 글자로 쓰려면 `\[표] 제목`, `\[@이름]` 처럼 `\` 를 붙입니다.
- **한/글에서 고친 내용**: 다시 변환하면 사라집니다. 내용은 원고에서 고치고, 한/글에서는 마지막 손질만 합니다.
